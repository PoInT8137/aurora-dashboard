# Тесты и скрипты проверки

Дашборду для работы не нужны, в страницу не входят. Запускаются на Node.js 24 (нужен встроенный SQLite для тестов сервера, остальному хватает 18+), зависимостей нет.

## Тесты

```bash
node --test tools/*.test.mjs                 # 114 тестов: сайт, переводы, Луна, клиент push, service worker
cd worker && npm test                        # 55 тестов сервера уведомлений
```

| Файл | Что проверяет |
|---|---|
| `parity.test.mjs` | **сайт и сервер уведомлений согласны, высокий ли шанс:** ~970 тыс. сравнений, 7 точек, реальная высота Солнца весь год (полярный день, ночь, сумерки); разбор ответов Open-Meteo и NOAA; одна и та же модель погоды |
| `push-client.test.mjs` | подписка браузера: разрешение, ключ, регистрация на сервере, откат при отказе сервера, потерянная подписка, отозванное разрешение, зависшая подписка |
| `sw-push.test.mjs` | service worker: показ push, запасное уведомление при недоступном сервере, приложение в фокусе, нажатие на уведомление, полнота оболочки |
| `moon.test.mjs` | **Луна против Морской обсерватории США:** 50 фаз за 2026 год, восходы и заходы в двух точках, освещённость, полярные случаи (Луна не заходит, не восходит, видна 17 минут), пороги помехи на границах. Эталон — `fixtures/usno-moon-2026.json` |
| `moon-ui.test.mjs` | Луна на странице: фактор и пояснение в вердикте, строка в окне наблюдения, чип на вкладке «Куда ехать»; уровень вердикта от Луны не зависит |
| `i18n.test.mjs` | **переводы:** те же ключи и подстановки во всех словарях, нет кириллицы в английском и китайском, каждый ключ из `app.js` и `index.html` существует, а в словаре нет мёртвых; определение языка (адрес, выбор, браузер, запасной английский); формы множественного числа; страница на каждом языке (время, возраст данных, вердикт, «Куда ехать», ошибки загрузки); нажатие на переключатель; уровень вердикта не зависит от языка |
| `app-ui.test.mjs` | тексты ошибок (включая настоящие `DOMException`), кнопки не залипают при сбоях |
| `app-sandbox.mjs` | не тест: песочница, запускающая `app.js` в Node без браузера |

`app.js` запускается в песочнице без браузера: DOM заменён заглушкой, время и сеть подменяются. Так расчёты проверяются на сотнях тысяч комбинаций входных данных.

## Одноразовые скрипты

Ими проверялись решения, описанные в основном README.

```bash
node tools/compare-models.js      # снимок облачности по 12 моделям Open-Meteo
node tools/check-consistency.js   # согласованность ярусов и суммы за 48 часов
node tools/compare-formulas.js    # взвешенная сумма против модели перекрытия
```

**compare-models.js** запрашивает у каждой модели текущую облачность и три яруса и проверяет неравенство `max(ярусы) ≤ всего ≤ сумма(ярусы)`, обязательное при любом допущении о перекрытии слоёв. Этим скриптом обнаружено, что `best_match` для Мурманска выбирает MET Norway и что у неё это неравенство нарушается.

**check-consistency.js** делает то же самое по всему 48-часовому почасовому ряду и считает долю часов с нарушением — чтобы отличить разовый сбой от систематического.

**compare-formulas.js** сравнивает две формулы сведения ярусов в одно число на крайних и смешанных случаях и прогоняет их по всему пространству значений с шагом 5 %.

Результаты и выводы — в разделе [«Почему выбрана эта модель прогноза»](../README.md#почему-выбрана-эта-модель-прогноза).
