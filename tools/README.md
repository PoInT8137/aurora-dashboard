# Тесты и скрипты проверки

Дашборду для работы не нужны, в страницу не входят. Запускаются на Node.js 24 (нужен встроенный SQLite для тестов сервера, остальному хватает 18+), зависимостей нет.

## Тесты

```bash
node --test tools/*.test.mjs                 # 179 тестов: сайт, настройки, переводы, Луна, клиент push, service worker
cd worker && npm test                        # 63 теста сервера уведомлений
```

## Одноразовые скрипты

Ими проверялись решения, описанные в основном README.

```bash
node tools/compare-models.js      # снимок облачности по 12 моделям Open-Meteo
node tools/check-consistency.js   # согласованность ярусов и суммы за 48 часов
node tools/compare-formulas.js    # взвешенная сумма против модели перекрытия
```

**compare-models.js** запрашивает у каждой модели текущую облачность и три яруса и проверяет неравенство `max(ярусы) ≤ всего ≤ сумма(ярусы)`, обязательное при любом допущении о перекрытии слоёв. Этим скриптом обнаружено, что `best_match` для Мурманска выбирает MET Norway и что у неё это неравенство нарушается.

**check-consistency.js** делает то же самое по всему 48-часовому почасовому ряду и считает долю часов с нарушением — чтобы отличить разовый сбой от систематического.

**compare-formulas.js** сравнивает две формулы сведения ярусов в одно число на крайних и смешанных случаях и прогоняет их по всему пространству значений с шагом 5 %.

Результаты и выводы — в разделе [«Почему выбрана эта модель прогноза»](../README.md#почему-выбрана-эта-модель-прогноза).
