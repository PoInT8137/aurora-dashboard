# Код приложения

Обычные скрипты без модулей и сборки: функции и переменные верхнего уровня — глобальные и видны
из всех файлов. Порядок подключения задан в `index.html` и важен только для кода, который
выполняется сразу при загрузке (например, `TONE` в `now.js` нужен `CHECK_MARKS` в `notify.js`);
вызовы функций друг друга внутри обработчиков от порядка не зависят.

| Файл | Что внутри |
|---|---|
| `base.js` | настройки запросов, точка наблюдения, утилиты, `fetchJson`, форматирование, кэш последних удачных ответов |
| `now.js` | вкладка «Сейчас»: Луна (тексты), шкалы и оценка, Kp, солнечный ветер, OVATION, погода, облачность, прогноз Kp |
| `night.js` | окно наблюдения на ближайшую ночь и график ночи по часам |
| `tonight.js` | вкладка «Куда ехать ночью»: окна по семи точкам, прогноз NOAA на 27 дней |
| `map-tab.js` | вкладка «Карта» (схема — в `../map.js`) |
| `clouds.js` | слой облачности на карте: сетка узлов, один запрос к Open-Meteo, ползунок по часам |
| `notify.js` | уведомления страницы, проверка работоспособности, интерфейс уведомлений с сервера (подписка — в `../push.js`) |
| `page.js` | вкладки, вердикт, выбор точки, строка статуса, обновление данных |
| `share.js` | «Поделиться»: ссылка на нужном языке и QR-код |
| `settings.js` | настройки отображения и язык интерфейса |

`../app.js` — точка входа: `init()` и регистрация service worker. Расчёты — в `../core.js`,
общем с сервером уведомлений.

До разбиения это был один `app.js` на 3500 строк; части нарезаны по его разделам без изменений
кода — склейка частей побайтно совпадала с прежним файлом.
